## 3. 追加回路

### 3.1 CH4-CH7 リレー駆動回路（v3と同一構成×4）

各チャンネル:
```
GPxx → R(330Ω) → PC817(LED) → GND         [3.3V側]
PC817(TR) → R(100Ω) → 2N7002(Gate)         [5V側]
2N7002(Drain) → K(リレーコイル) → 5V
2N7002(Source) → GND
+ 10kΩプルダウン(Gate-GND)
+ 1N4148フライバックダイオード(リレーコイル並列)
+ 330Ω + LED(状態表示)
+ 3ピン端子台(NO/COM/NC)
```

追加部品 (CH4-7, 各ch同構成):
| RefDes | 値 | 用途 |
|--------|-----|------|
| R17-R20 | 330Ω | フォトカプラ入力抵抗 |
| U6-U9 | PC817 | フォトカプラ |
| R21-R24 | 100Ω | ゲート抵抗 |
| R25-R28 | 10kΩ | プルダウン抵抗 |
| Q5-Q8 | 2N7002 | MOSFET |
| D5-D8 | 1N4148 | フライバックダイオード |
| R29-R32 | 330Ω | LED電流制限抵抗 |
| LED5-LED8 | Red | インジケータLED |
| K5-K8 | SANYOU_SRD | リレー |
| J9-J12 | Conn_01x03 | 出力端子台(NO/COM/NC) |

### 3.2 I2C Grove コネクタ

```
J8: Grove 4pin (JST PH互換 1x4)
  pin1 = SDA (GP4)
  pin2 = SCL (GP5)
  pin3 = 3V3
  pin4 = GND

R33: 4.7kΩ SDA プルアップ (SDA ─ 3V3)
R34: 4.7kΩ SCL プルアップ (SCL ─ 3V3)
```

用途: I2Cリレーモジュール、I2Cセンサー、I2C LCDなどの外付け拡張

## 7. 注意事項

- **GP16-19はSPI0ピン**: W5500-EVB-Picoを同時使用する場合はSPIと競合する。
  本基板はPico 2 W (WiFi) 前提なのでSPI0は使わない。
  W5500使用時はgrove_shield_v3を使うこと（棲み分け済み）。
- **電源容量**: 8リレー同時ON時の最大電流 = 50mA × 8 = 400mA。
  USB給電（500mA）だとPico自体の消費も含め余裕がない。
  J7(外部5V)から1A以上の電源供給を推奨。
- **I2C Grove**: 3.3Vレベル。5Vデバイスを繋ぐ場合はレベル変換が必要。
